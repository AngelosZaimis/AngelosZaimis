
# 👋 Hi, I'm Angelos Zaimis

**Software & AI Engineer** based in Zurich, currently at **Nu.education**, building backend-heavy, full-stack systems.

My core is **Java and Spring Boot**. I have production experience designing and running microservice architectures in enterprise environments, where **reliability, security, clean architecture, and long-term maintainability** come first. That is the standard I bring to every system I build.

On top of that foundation, I build **AI-powered backend services with Python and FastAPI**: LLM integrations, RAG pipelines, and agent workflows with LangChain / LangGraph, designed for production rather than demos.

I'm full-stack with a clear backend focus. I'm comfortable shipping frontends in **React / Next.js** when the product needs them. I also write **Go** for performance-oriented services and to sharpen my understanding of concurrency and systems design.
